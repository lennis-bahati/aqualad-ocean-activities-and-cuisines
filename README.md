🌊 Aqualad - Ocean Activities & Cuisines

Aqualad is a modern, responsive web application designed for booking unique ocean adventures and gourmet seafood culinary experiences[cite: 1]. Built with a sleek "glassmorphism" aesthetic, it delivers a seamless e-commerce and booking flow right in the browser.

## ✨ Key Features

* **Interactive Package Explorer:** Browse multiple signature packages (*Deep Sea Experience*, *Sea Side Chill*, and *Aqua Man Ultimate*) with detailed modal views[cite: 1].
* **Dynamic Cart Management:** Add items, adjust quantities, calculate subtotal and conservation fees, and clear or check out seamlessly[cite: 1].
* **Persistent State:** Uses browser `LocalStorage` to save your cart items even if you refresh or leave the page[cite: 1].
* **Mobile-Responsive Design:** Fully optimized with a custom collapsible mobile hamburger menu and fluid grid scaling for phones, tablets, and desktops[cite: 1].
* **Custom UI Components:** Features glassmorphism card styling (`backdrop-filter`), animated toast notification alerts, and interactive SVG marine graphics[cite: 1].

## 🛠️ Tech Stack

* **Markup:** HTML5[cite: 1]
* **Styling:** Tailwind CSS (via CDN)[cite: 1]
* **Logic & Interactivity:** Vanilla JavaScript (ES6+)[cite: 1]
* **Icons & Fonts:** Ionicons[cite: 1] & Google Fonts (*Poppins*)[cite: 1]

## 🚀 Quick Start / How to Run Locally

If you want to run or test this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/YOUR-USERNAME/aqualad-booking-app.git](https://github.com/YOUR-USERNAME/aqualad-booking-app.git)

2.**Navigate into the project directory:**
   Bash
  cd aqualad-booking-app

3.**Open the application:**
   Simply double-click Aqualad.html, or open it using a live server extension in your code editor (like VS Code's Live Server).
